# 健身紀錄反饋 APP (Fitness Tracker & Feedback App)

這是一個專為健身愛好者設計的訓練紀錄與動態反饋系統。透過系統化的流程，協助使用者在訓練前、訓練中、訓練後獲得即時的科學化數據回饋。

## 功能特點

- **A. 訓練前：計畫與準備**
  - 支援「按計畫訓練」與「自由訓練」雙模式。
  - 自動載入預設動作、組數與目標重量。
- **B. 訓練中：數據錄入與即時回饋**
  - 每組完成後錄入實際重量與次數。
  - 自動啟動組間休息計時（模擬）。
  - **動態調整演算法**：連續兩組輕鬆達成時，自動提示增加 2.5kg。
- **C. 訓練後：總結與分析**
  - 自動計算本次訓練總負荷量 (Total Volume)。
  - 記錄突破個人紀錄 (PR)。
  - 整合自覺強度 (RPE) 評估。
  - 自動生成訓練趨勢圖表。
